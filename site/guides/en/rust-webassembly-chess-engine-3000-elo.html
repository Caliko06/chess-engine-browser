The engine behind calichess.cc was written from scratch in Rust, measured at about 3039 Elo on the CCRL Blitz scale, and compiled to WebAssembly so it runs in a browser tab. This is how, with the numbers.

In one breathEvery change to the engine had to win a match of real games against the previous version before it was kept. Changes that could not prove they helped were thrown away, even when they looked smart.

The rule: games decide, not intuition

Chess engines are full of ideas that sound good and make the engine weaker. So each change played the previous version in a sequential probability ratio test (SPRT): keep playing games until the statistics can say "better" or "not better" with set confidence.

Measuring strength honestly

Beating your own older versions only says you improved, not how strong you are. For that, the engine played 120 games against each of five versions of Stash, an open-source engine with known ratings.

Speed: same thinking, less time

The biggest single gain did not change what the engine thinks at all. It searched the exact same tree of moves, node for node, about 1.9 times faster: hopeless moves are now thrown out before they are played on the board, memory is reused instead of cleared at every step, and scores already computed are kept. A fixed benchmark visited exactly 6,891,892 positions before and after, which proves the thinking did not change. That alone was worth about 117 Elo.

Into the browser

Rust compiles to WebAssembly with no code changes. The engine runs in a background thread (a Web Worker), so the board never freezes while it thinks. The download is 191 KB compressed. In the browser it reaches 1.0 to 1.5 million positions per second, and the move finder answers at depth 9 to 10 in about 0.2 seconds.

Your moves stay in your browser: the build fails if any network call appears in the engine, the app or the build scripts. The site itself only counts visits, with Cloudflare Web Analytics and no cookies.

One bug taught the biggest lesson: adding "skip captures that lose material" first cost 80 Elo. The idea was right; the function that judges a trade had a bug. After fixing it, the same idea gained +60.
